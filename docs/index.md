# BMS 组件文档中心

这是 `BMS` 组件体系的统一文档站，主要承载三类内容：

- 组件使用文档
- 组件评估与治理文档
- 后续 npm 包抽离与重构沉淀

## 快速入口

- [组件总览](/components)
- [组件评估](/overview)
- [组件治理](/governance)

## 组件分类

- 基础能力：权限、错误边界、底部操作栏、数值范围输入
- 表单与上传：`ProForm`、附件上传、上传抽屉
- 数据展示与选择：`ProTable`、远程搜索、树选择、PDF 预览
- 布局与导航：页签、菜单、页头、缓存
- 反馈与状态：确认框等轻量反馈组件
- 业务组件：地址、合同、流程、日志、导入等业务能力组件
