# 通用能力说明

这一组文档用于沉淀当前 BMS 体系中已经具备复用价值、并且适合逐步推广到多个子应用的 Hook 与工具能力。

## 当前分类

### Hooks

- `useQueryParams`：用于读取 URL 查询参数
- `useDataDict`：用于统一消费字典数据
- `useGoodsOwner`：用于统一处理货主相关数据

### Utils

- `storage`：统一访问本地存储
- `dict`：把字典数据转换为下拉或搜索可消费结构
- `permission`：处理路由、菜单、权限树相关查找与组织

## 建议阅读顺序

1. 先看 [Hooks 与 Utils 治理建议](../hooks-utils-governance)
2. 再按分类进入对应能力文档
3. 如果是页面开发，优先看 Hooks
4. 如果是数据整形、权限树或缓存处理，优先看 Utils

## 适用范围

当前这批能力文档主要面向：

- 使用同一套基础设施与权限体系的子应用
- 需要复用表单、字典、菜单、货主等通用逻辑的开发场景
- 希望减少页面重复造轮子的日常开发

它们并不都属于完全独立、可脱离上下文运行的底层能力。使用前应先关注每篇文档中的依赖前提与边界说明。
